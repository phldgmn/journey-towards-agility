Analyzing time-adjusted delivery options
Sequencing is needed because resource lim-itations and dependencies between elements
typically make it impractical to develop all the
elements during a single period. To evaluate

alternate sequencing options, we must first

calculate each elementÕs NPV for each feasible

period. Table 5 shows the 
sequence-adjustedNPVs for the travel agency project, calculatedat a discount of 2.5 percent per quarter. For

example, if MMF C is developed in Period 1,

its SANPV is $266K; if itÕs developed in Period

5, its SANPV decreases to $145K.The IFM heuristicIn small projects with few elements, itÕs
clearly possible to calculate each feasible se-
quenceÕs NPV to categorically determine the

best sequence. (WeÕve built an analysis tool

that can successfully calculate sequences of up
to 13 MMFs.) However, as the number of fea-

sible delivery sequences grows exponentially
with the number of elements, this approach

quickly becomes impractical. To address this

problem, we introduce the IFM heuristic.The IFM heuristic views sequencing op-
tions as strandsÑsequences of elements linkedby precursor relationships. Individual ele-
ments are special cases of strands. We decom-

pose a string of dependent MMFs such as M1M2M3into the strands M1, M1M2,M2M3, and M1M2M3. Similarly, a precursor
relationship such as M1M2and M1M3,results in strands M1, M1M2, and M1M3. Forelements that take more than one period to de-

developmentYou can use IFM to identify concurrent
schedules by simply selecting multiple ele-

prohibit a step-by-step example illustrating

ods 4 and 11 for the linear sequence.These results illustrate some of the trade-

quential development. A concurrent schedule

velopment of more features in less time and

because it tends to increase NPV. However, it

might require a higher initial investment than
the organization can fund.You can sometimes improve a projectÕs
fundability by considering a hybrid solution
that gradually ramps up the project and intro-
duces concurrency once earlier MMFs have
started to generate revenue. This can decrease
the initial funding requirement and return
NPV somewhere within the range of the linear
and fully concurrent solutions.If a project needs both to maintain a lowerlevel of funding and to attempt to reach self-
funding status sooner, you can promote

MMFs that will return value more quickly. In

general, the IFM heuristic optimizes value

over the entire analysis window; however, for

sequencing purposes only, you can shorten the

number of periods over which each element is
analyzed. This causes the heuristic to favor el-
ements that immediately start generating rev-

forward the self-funding point.
